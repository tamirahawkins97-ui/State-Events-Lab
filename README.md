# State-Events-Lab

## React State & Events Lab

A hands-on lab designed to demonstrate core React concepts, focusing on component structure, managing state with `useState`, handling user events, and rendering parent/child components to the UI.

---

## 📌 Overview

This repository contains practical exercises for building dynamic, interactive user interfaces in React. You'll explore how component trees are structured, how data flows between parents and children, and how state updates trigger UI re-renders.

### Key Concepts Covered
* **Parent/Child Architecture:** Structuring applications into modular, reusable components and placing them within the UI.
* **State Management:** Declaring and updating component state using the `useState` hook.
* **Event Handling:** Capturing user interactions (e.g., `onClick`, `onTextChange`, etc) to update application state.
* **Props & Unidirectional Data Flow:** Passing data down from parent to child components and lifting state up via callbacks.
* **Dynamic UI Rendering:** Using state to dynamically render and update elements in the DOM.
